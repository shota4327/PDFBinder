## 📖 概要
**PDF Binder** は、直感的なタイル状グリッドでPDFページを自由に並び替え・回転・結合・分割・白紙追加できる「バインダー整理機能」と、ペン・蛍光ペン・直線・消しゴムによる「手書きアノテーション機能」を融合した、軽快なWindowsデスクトップアプリケーションです。

商用・非商用問わず誰でも安心して利用・再配布できるよう、寛容型オープンソースライセンス（MIT / Apache-2.0 / BSD）のコンポーネントのみで構築されています。

## ✨ 主な機能

### 1. 詳細ビュー（単一ページ／縦連続表示）
- **選べる2つの表示モード**:
  - **単一ページ表示（初期値）**: 1ページずつ集中して閲覧・手書き記入。ページが画面に収まっている時はマウスホイールで前後のページを素早くめくり、拡大表示中はページ内をスクロールして上下端に達した状態でスムーズに前後のページへ切り替え（回転量に応じた即時追従・高速ページ送りに対応）
- **複数ドキュメントの切り替え＆個別終了**: タイトルバー中央のプルダウンメニューから、開いている複数のPDFを即座に切り替え。ドキュメントごとにUndo/Redo履歴や表示モード・ズーム率が独立して保持され、作業状態を損なわずに並行作業が可能。各ファイルの「×」ボタンから保存確認付きで個別終了にも対応
- **単一インスタンス＆関連付けタブ統合（「プログラムから開く」対応）**: すでにPDF Binderが起動している状態でエクスプローラーからPDFをダブルクリック（または「プログラムから開く」）した場合、別ウィンドウを多重起動せず、直近に操作していた既存ウィンドウの新しいタブとして即座に追加オープンし最前面に表示（同ファイルが既に開かれている場合は重複せず該当タブをアクティブ化）。新規ウィンドウで開きたい場合はコマンドライン引数 `--new-window`（または `-n`）を指定可能
- **外部PDFのドラッグ＆ドロップ**: エクスプローラーからPDFをドラッグ＆ドロップして別ファイルとして軽快に追加オープン（ドラッグ案内オーバーレイ表示）。ツールバーの「追加」ボタンからは現在のPDFへのページ差し込み結合に対応
- **ズーム連動動的プレビュー**: 最大3200%までの超高倍率ズームに対応。高倍率に応じた適応型スナップ目盛りにより快適に拡大縮小でき、現在のズーム倍率に合わせてリアルタイム・デバウンス描画。縮小表示時も細線が消失せず文字がかすれず、拡大時もくっきり鮮明
- **手書きアノテーション**:
  - ペンツール（自由な色・太さでの滑らかなベクター手書き）
  - 蛍光ペンツール（下の文字が透けて見える半透明ハイライト描画）
  - 消しゴムツール（一筆消しの「ストローク消し」と、ピクセル消しの「部分消し」）
  - 直線トグル（ペン・蛍光ペンでまっすぐ直線を引けるトグルモード）
  - 筆圧トグル（スタイラスペンの筆圧による線の強弱・太さ変化を反映するトグルモード。デフォルトOFFで均一な線を描画）
  - 太さ・色の状態保持（ツール切り替え時も直前の太さ・色を独立記憶）
- **テキスト選択・コピー＆リンク機能**:
  - 文字選択ツールにより、PDF内の文字をマウスドラッグで自由にハイライト選択して `Ctrl+C` や右クリックでクリップボードへコピー可能（リンクと干渉せず純粋に文字選択が可能）
  - 移動（手のひら）ツール使用時、外部WebサイトへのURLリンク（既定のブラウザで直接起動）およびPDF内リンク（該当ページへ即時ジャンプ）をクリック可能
  - 手書きペンや消しゴムツール使用時は手書き入力を最優先し、誤動作を完全に防止
- **パームリジェクション & タッチ操作**: ペン使用時は手首の誤動作を完全防止。指1本で画面移動（パン）、指2本で直感的なピンチズームに対応
- **高品位PDF合成**: 手書き内容は拡大や印刷でも劣化しないベクター＆透過合成で保存

### 2. 俯瞰グリッド（バインダー整理）
- **純粋なサムネイル一覧配置**: 余計なカード枠やボタンを排した、美しいサムネイル画像のみのタイル一覧。選択時は2pxのアクセント枠線と青い光彩で明瞭にハイライト
- **Windows標準準拠のマウス選択**: 通常クリックで単一選択、Ctrl+クリックで個別トグル、Shift+クリックで連続範囲選択、余白クリックで全解除に対応
- **余白ドラッグによる矩形選択（ラバーバンド選択）**: 余白からドラッグして囲むことで複数ページを一括選択（Ctrl併用で追加選択）
- **浮遊ドラッグ＆ドロップ並び替え**: サムネイルをドラッグすると浮遊プレビュー（Drag Adorner）と青い縦の挿入バーが表示され、単一または複数選択ページを直感的に並び替え
- **外部PDFの指定位置ドラッグ＆ドロップ結合**: エクスプローラーからPDFファイルをグリッド上にドラッグすると青い挿入バーが表示され、指定位置にページを直接差し込み結合（ツールバーの「追加」ボタンからも結合可能）
- **ドラッグ中スクロール＆オートスクロール**: ページ並び替え・外部PDFドラッグ中やラバーバンド選択中にマウスホイールで縦スクロールが可能。さらに画面の上下端にカーソルを近づけると自動でスムーズにスクロール（端に近いほど高速化）
- **必要な時だけ切り替え**: 「表示」タブからいつでもワンクリックで切り替え。サムネイルはグリッド表示時にオンデマンド生成されるため、大容量ファイルも待たずに開けます
- **スムーズ連携**: サムネイルをダブルクリックすると詳細ビューへ切り替わり、該当ページへ自動スクロール
- **ページ操作**: 時計回り/反時計回りの回転、ページの削除、白紙ページの追加（隣接サイズ自動継承）
- **分割＆抽出**:
  - 選択した複数ページを別ファイルとして抽出（分割）、または1ページずつ個別PDFに一括分割
  - **ページ分割**: 全ページの表示向きに応じた長辺を2等分（A3横→A4縦2枚、A3縦→A4横2枚等）に一括分割（手書きストロークも位置に応じて自動切断・引き継ぎ、Undo/Redo対応）
- **安心の操作性**: ページ操作の Undo / Redo（元に戻す・やり直す）対応
- **未保存変更の保護**: 編集後に保存せずウィンドウを閉じる場合や、別のPDFを開く場合に保存確認ダイアログを表示（単に開いて閉じる閲覧時は確認なしで即座に終了）
- **ファイルロック回避**: 読み込み元ファイルをロックせず、安全な上書き保存・別名保存に対応

### 3. 高度な印刷機能と面付け（インアプリ・オーバーレイ）
- **快適な印刷ダイアログ (`Ctrl+P`)**: 「PDF編集」タブの印刷ボタンまたはショートカットから、ダークテーマに調和した左右2分割オーバーレイを起動
- **リアルタイム用紙プレビュー**: 用紙の向き・サイズ・手書きメモを反映した用紙プレビューを自動Fit表示。下部ナビゲーションで各用紙をスムーズにめくって確認可能
- **多彩な印刷モード**:
  - **用紙サイズに合わせる (Fit)**: 用紙の余白に合わせて1ページずつ最大化印刷
  - **１ページに集約 (N-up)**: 1枚の用紙に 2 / 4 / 8 ページをグリッド状に縮小配置
  - **冊子形式（製本）**: 二つ折り中綴じ用の面付けを自動計算（不足ページは白紙を自動補完、自動で横向き・両面短辺とじに連動）
- **プリンター印刷設定連携（プロパティ）**: プリンター選択プルダウン横の歯車アイコンボタンから、選択中プリンターのドライバー固有「印刷設定」ダイアログを直接呼び出し。ダイアログで指定した用紙サイズ・向き・部数・両面設定をPDF Binder画面へ即座に自動反映するとともに、カラー/モノクロ、給紙トレイ、印刷品質等のドライバー固有設定も内部保持して実際の印刷ジョブへ引き継ぎ
- **柔軟な設定**: プリンター選択、印刷部数（1〜99部）、向き（縦/横）、用紙サイズ（A4/A3）、両面印刷（片面/長辺とじ/短辺とじ）、印刷範囲（全ページ/現在のページ/カスタム指定）
- **設定保持**: アプリ起動中は設定変更を保持（次回印刷時も前回の設定を引き継ぎ、再起動時に初期化）

### 4. 表示タブと表示オプション
- **ビュー切り替え**: 「詳細」と「グリッド」を相互排他ボタンで分かりやすく選択・強調表示
- **表示オプション（詳細ビュー）**:
  - 「100%」（等倍）、「ウィンドウにあわせる」（ウィンドウ全体に収まるよう自動調整・デフォルト）、「幅にあわせる」（横幅いっぱいに自動調整）の3種
  - 単一ページ表示時はページ切り替え時も新しいページ寸法に自動追従フィット。連続表示時はスクロール途中で拡大率を変更せず、ウィンドウリサイズ時やボタン押下時のみカレントページ基準で再計算
- **ページ配置（詳細ビュー）**:
  - 「単一」（初期値）と「連続」をワンクリックで切り替え可能
- **キーボードショートカット**: `PageUp` / `PageDown` による前後のページ移動に対応
- **拡大縮小の一本化**: 詳細ビュー（50%〜3200%の適応型ステップ拡大縮小）とグリッドビュー（サムネイルサイズ）のズーム操作を一本化。縮小、等倍/標準リセット、拡大を直感的に操作可能

### 5. 高機能ステータスバー
- **ページ移動コントロール**: 左端に `< ページ [ 1 ] / 2 >` を配置。前後のページへワンクリックでスクロール移動できるほか、ページ番号入力欄に数値を直接入力して Enter キーで即時ジャンプ可能
- **クイックズームコントロール**: 右端に `[-] 100% [+]` を配置し、表示タブを開かなくても常時拡大・縮小・等倍リセットが可能
- **快適な操作性**: ステータスバーの高さを約1.5倍に拡大し、日常的な閲覧・移動・拡大縮小のタッチ・マウスクリックが快適に行えます

### 6. モダンなチャコールダークテーマ
- **目に優しいチャコールグレー＆VS Codeブルー**: VS Code風の彩度を抑えた無彩色グレー（`#1E1E1E` / `#252526`）と落ち着いたブルーアクセント（`#007ACC`）を基調とした洗練されたダーク配色により、青みの主張を抑えて長時間の閲覧・手書き作業での眼精疲労を大幅に軽減
- **原本用紙の忠実表示**: PDF用紙（紙面）自体は白地（原本色）をそのまま保持するため、カラー写真・図面・手書きペンの色合いを損なわずにハイコントラストで明瞭に確認可能
- **スリムなカスタムスクロールバー**: ダークテーマに美しく馴染むスリムで控えめなカスタムスクロールバーをアプリ全体に適用
- **高精細・ピクセル整合レンダリング**: `UseLayoutRounding` および `TextOptions.TextFormattingMode="Display"` を適用し、画面中央配置の要素やUI文字のサブピクセル滲みを根本から防止。日本語フォントを含め、すべての文字と枠線がくっきりとシャープに表示されます

### 7. ウィンドウ状態・設定の自動復元
- **前回のウィンドウサイズ復元**: 前回終了時のウィンドウサイズ（幅・高さ）および最大化状態を記憶し、次回起動時に復元
- **画面解像度・作業領域への自動追従**: 保存されたウィンドウサイズがディスプレイ作業領域（タスクバーを除外した画面領域）を超える場合、画面内におさまるよう自動調整
- **完全ポータブル対応**: EXEと同階層の `settings.json` に設定が保存されるため、フォルダ移動やUSBメモリ等での持ち運び利用にも完全対応

## 🛠 動作環境・開発環境
- **OS**: Windows 10 / 11 (64-bit)
- **ターゲットフレームワーク**: .NET 10.0 (`net10.0-windows`)
- **UIテクノロジー**: WPF (Windows Presentation Foundation)
- **主要ライブラリ**:
  - `PdfSharp` (MIT): PDF構造操作・保存
  - `PDFium` / `PDFiumSharp` (Apache-2.0 / BSD): 高速PDFレンダリング
  - `CommunityToolkit.Mvvm` (MIT): MVVMアーキテクチャ基盤
  - `Material Symbols Outlined` (Apache-2.0): オープンソースアイコンフォント（完全オフライン内包）

## 🚀 ビルド手順

### 開発環境の準備
- [.NET 10.0 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) 以降がインストールされていること。

### ビルド
```powershell
dotnet build
```

### 単体テストの実行
```powershell
dotnet test
```

### アプリケーションの起動（デバッグ）
```powershell
dotnet run --project src/PDFBinder.App
```

### 配布バイナリの発行
用途に合わせて、完全ポータブルな「自己完結版（単一EXE）」と、軽量・最速起動な「フレームワーク依存版（DLL分離形式）」を発行できます。
```powershell
# 両方のバージョンを一括発行（デフォルト）
.\build.ps1

# 自己完結版のみ発行（.NETランタイム内包・部分トリミング・単一EXE・完全オフラインポータブル）
.\build.ps1 -Target self-contained

# フレームワーク依存版のみ発行（OSの.NET 10デスクトップランタイムを利用・DLL分離・ReadyToRun・最速起動）
.\build.ps1 -Target framework-dependent
```
- **フレームワーク依存版（`dist/`）**: OSの .NET 10 デスクトップランタイムを利用する DLL 分離形式。ReadyToRun 最適化と Windows PE ローダーによる直接メモリマッピングにより、最速のコールドスタートと最小のメモリ消費を実現。
- **自己完結版（`dist/self-contained/PDFBinder.exe`）**: .NET 10 ランタイムを同梱した単一 EXE 形式。部分トリミング（`TrimMode=partial`）と ReadyToRun による最適化が施されており、.NET 未インストールの PC でも単体で完全オフライン動作可能。
