# Issue #9 検証報告書: 手書きエディタのパームリジェクションとタッチ操作

詳細手書きエディタ（`EditorInkCanvas`）において、スタイラスペン（デジタイザー）と手指によるタッチ入力を分離し、パームリジェクション（誤検知防止）および直感的なタッチジェスチャー（1本指パン・2本指ピンチズーム）の実装と検証が完了しました。

---

## 1. 実施した変更内容

### ① 計算ヘルパー層の追加
- `PinchZoomHelper.cs`:
  - 2本指のタッチ座標から、ピンチの拡大縮小率および指の中心位置（ビューポート基準）を算出。
  - 拡大縮小後もピンチした指の位置が画面上でズレない幾何学的中心追従オフセット計算を実装。
  - ズーム倍率のクランプ（0.5倍〜3.0倍）および負値オフセットの防止。

### ② コントロール・View層の機能強化
- `EditorInkCanvas.cs`:
  - **デバイス種別判別**: `StylusDevice.TabletDevice.Type` を使用し、スタイラスペン（`Stylus`）と手指タッチ（`Touch`）を厳格に分離。
  - **指タッチ描画の抑止**: `PreviewStylusDown` / `Move` / `Up` において `Touch` デバイスの入力を捕捉・ブロックし、指による不要なストローク描画を防止。
  - **パームリジェクション**:
    - ペンの接地（`StylusDown`）、ホバー近接（`StylusInAirMove`, `StylusInRange`）および離脱後の一定猶予時間を追跡。
    - ペン使用中は `PreviewTouchDown` をブロックし、筆記時の手首・手のひら接触による画面のガタつきを完全防止。
  - **マルチタッチ操作**:
    - 手指1本: スムーズな画面スクロール（パン）。
    - 手指2本: 指の中心位置を基準としたピンチズーム＆スクロール連動。
    - 指が画面から離れた際の座標クリーンアップ・タッチキャプチャ解放。
- `DetailEditorViewModel.cs`:
  - `MinZoom`（0.5）、`MaxZoom`（3.0）の定数化および直接指定用 `SetZoom(double zoom)` メソッドの追加。

### ③ ドキュメント同期
- `docs/basic_design.md`: パームリジェクションおよびタッチ操作仕様の追記。
- `docs/PROJECT.md`: 機能インベントリ（F47）の完了登録およびテスト件数更新。
- `README.md`: 機能一覧へのパームリジェクション＆タッチ操作の反映。
