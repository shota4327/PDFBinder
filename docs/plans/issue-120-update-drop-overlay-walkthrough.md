# Issue #120: ファイルドラッグ＆ドロップ時の案内オーバーレイ表示を新規オープン表示に更新 - 検証報告

## 概要
PDFファイルを開いている状態で外部から新しいPDFファイルをドラッグ＆ドロップした際、動作としては別ドキュメント（新しいタブ）として開くようになっていますが、画面上に表示されるドロップ案内オーバーレイの文言が「ここにPDFをドロップして末尾に追加・結合」「ドロップすると現在のドキュメントの末尾にページが追加されます」となっており、実際の動作と表示に乖離がありました。

事前のヒアリング（/grill-me）に基づき、オーバーレイの表示文言およびアイコンを実際の動作に合わせて更新し、関連ドキュメント（基本設計書およびREADME）の記述も最新仕様へ同期しました。

---

## 実施内容

### 1. View / XAML (`src/PDFBinder.App/MainWindow.xaml`)
- ドロップ案内オーバーレイのアイコンおよび文言を更新:
  - **アイコン**: `&#xE9FC;` (`upload_file`) → `&#xEAF3;` (`file_open`) （リボンの「開く」アイコンと統一）
  - **タイトル**: `ここにPDFをドロップして末尾に追加・結合` → `ここにPDFをドロップして開く`
  - **サブタイトル**: `ドロップすると現在のドキュメントの末尾にページが追加されます` → `ドロップするとPDFファイルが新しいタブで開かれます`

### 2. ドキュメント同期
- **`docs/basic_design.md`**:
  - セクション 6.5「グリッド俯瞰ビュー」の「外部ファイルドラッグ＆ドロップ」項目の記述を、現在の仕様（新しいタブとして開く）および更新後のオーバーレイ文言に更新。
- **`README.md`**:
  - セクション 2「俯瞰グリッド（バインダー整理）」内の「外部PDFの追加結合」記述を、ツールバーの「追加」ボタンによる結合およびドラッグ＆ドロップによる別ファイルオープンの実態に合わせて整合化。
