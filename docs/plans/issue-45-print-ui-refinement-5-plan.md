# Issue #45 印刷ダイアログ UI/UXデザイン調整（第5弾）実装計画

## 概要
ユーザーからの追加フィードバックに基づき、印刷設定パネルの用紙設定の配置順序と間隔の調整、ボタン幅の最適化、およびページ指定・集約数設定の右横インライン配置を実施します。

---

## 決定事項（ユーザー確認済み）
1. **用紙サイズと用紙の向きの位置入れ替え＆余白詰め**:
   - 左列を「用紙サイズ（A4 / A3）」、右列を「用紙の向き（縦 / 横）」に入れ替えます。
   - 列間の余白を従来の 16px から 10px〜12px に詰め、すっきりと収まりの良いレイアウトにします。
2. **印刷範囲のボタン幅（120px）＆右横テキストボックス配置**:
   - 印刷範囲（すべて／現在のページ／ページ指定）の各ボタン幅を `Width="120"` に設定します。
   - 「ページ指定」ボタンの右横（インライン）にテキストボックスを配置し、ページ指定選択時のみ表示します。
3. **印刷モードのボタン幅（140px）＆右横集約数プルダウン配置**:
   - 印刷モード（サイズに合わせる／1ページに集約／冊子(製本)）の各ボタン幅を `Width="140"` に設定します。
   - 「1ページに集約」ボタンの右横（インライン）に集約数ドロップダウンを配置し、集約モード選択時のみ表示します。
