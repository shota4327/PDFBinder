# Issue #76 グリッドビューの見た目変更・操作性向上 実装計画

## 1. 概要
PDFページの俯瞰グリッドビュー（`GridView`）を従来のカードコンテナ形式から、余計な装飾を排した洗練されたサムネイル一覧デザインへと刷新します。
あわせて、Windows標準準拠のクリック・範囲選択、余白ドラッグによる矩形（ラバーバンド）複数選択、浮遊感のあるドラッグアドーナーと青い挿入バーによる直感的なページ並び替え、および外部PDFドラッグ＆ドロップ時の任意位置へのページ差し込み・結合機能を実現します。

---

## 2. 決定された仕様一覧（インタビュー結果）
1. **サムネイル外観の純化**:
   - 従来のカード枠（ヘッダー・フッター）を廃止し、余白とドロップシャドウを効かせたサムネイル画像そのものをタイル配置。
   - ページ番号表示（P.1 等）、チェックボックス、およびカード上のボタン（回転・削除）は全廃。
   - 通常時は用紙ライクな控えめな影、選択時は2pxのアクセント枠線（`#007ACC`）と青い光彩（シャドウ）を付与。
2. **マウス選択インタラクション（Windowsエクスプローラー準拠）**:
   - **通常クリック**: 対象ページのみを選択（他は解除）。
   - **Ctrl + クリック**: 対象ページの選択/解除トグル。
   - **Shift + クリック**: アンカーページから対象ページまでの連続範囲選択。
   - **余白クリック**: 全ページの選択解除。
   - **ダブルクリック**: 従来通り「詳細手書きエディタ」を開く。
   - **右クリック**: 特別なコンテキストメニューは表示しない（リボンメニューやショートカットキーで操作）。
3. **余白ドラッグによる矩形選択（ラバーバンド選択）**:
   - サムネイル以外の余白部分からドラッグを開始すると、半透明の青い矩形（枠線付き）を描画。
   - 矩形と交差・接触したサムネイルを選択状態に更新。
   - 通常ドラッグは新規選択、Ctrlキー併用時は既存の選択状態を保持したまま追加。
4. **ページ並び替えドラッグ＆ドロップ**:
   - 単一ページおよび複数選択ページのドラッグに対応。
   - ドラッグ中、カーソル位置に浮遊プレビュー（半透明＋拡大・影効果のDrag Adorner）を表示。
   - ドラッグ元のサムネイルは半透明化（Opacity 0.4）。
   - ドロップ先となるページ間に縦方向の青いバー（挿入インジケーター）を表示。
   - ドロップ時に一括して移動・並び替えを実行（Undo/Redo対応）。
5. **外部PDFドラッグ＆ドロップ（差し込み結合）**:
   - GridView上に外部PDFファイルをドラッグしてきた場合、ページドラッグと同様に挿入位置の青いバーを表示。
   - ドロップ時に、その位置へ外部PDFの全ページを順番に読み込んで挿入（Undo/Redo対応）。
   - ドキュメントが空の場合やタブバーへのドラッグは、従来通り新規タブ（または新規ドキュメント）として開く。

## 3. 実装アプローチ & 変更対象コンポーネント

### 3.1 Views / コントロールレイヤー
- **[MODIFY] `src/PDFBinder.App/Views/GridView.xaml`**:
  - コンテナ（Borderヘッダー・フッター・チェックボックス・ボタン群）を撤去し、サムネイル境界のみで構成。
  - サムネイル用スタイル（選択時の青枠・青光彩、未選択時の紙影）を定義。
  - 矩形選択用のラバーバンド Canvas / Border（青半透明の `SelectionBox`）をオーバーレイ配置。
  - ドラッグ時の青い挿入位置インジケーター（`InsertionAdorner` またはオーバーレイ線）を実装。
- **[MODIFY] `src/PDFBinder.App/Views/GridView.xaml.cs`**:
  - クリック・Ctrl・Shift・余白クリック判定ロジックの実装。
  - ラバーバンド矩形ドラッグの開始・追従・ヒットテスト判定（サムネイルのBoundsとの交差判定）ロジック。
  - ページドラッグ開始時のDrag Adorner生成と表示。
  - ドラッグオーバー時の挿入位置インデックス計算および青いバーの表示制御。
  - 内部ページドロップ処理（複数ページ一括移動対応）。
  - 外部PDFドラッグオーバー＆ドロップ処理（青いバー表示、位置指定挿入呼び出し）。
- **[NEW] `src/PDFBinder.App/Controls/DragAdorner.cs`**:
  - カーソルに追従するドラッグ浮遊プレビュー描画用Adorner。
- **[NEW] `src/PDFBinder.App/Controls/InsertionBarAdorner.cs`**:
  - ドロップ先のページ間に青い縦バーを描画するAdorner。

### 3.2 ViewModels / ロジックレイヤー
- **[MODIFY] `src/PDFBinder.App/ViewModels/MainViewModel.cs`**:
  - 複数選択ページの指定位置への一括移動メソッド `MovePages(IReadOnlyList<int> oldIndices, int newIndex)` の追加（Undo/Redo対応）。
  - 指定位置へのPDFファイル挿入メソッド `InsertPdfFilesAsync(IEnumerable<string> filePaths, int insertIndex)` の追加（Undo/Redo対応）。
  - 範囲選択ヘルパー（インデックス範囲の `IsSelected` 更新）。
- **[MODIFY] `src/PDFBinder.App/MainWindow.xaml.cs`**:
  - GridView表示中における外部PDFドラッグ時の全画面オーバーレイ表示の抑制（GridView側の挿入バーを優先表示するため、コンテキストに応じた `IsDragOver` 制御への修正）。
