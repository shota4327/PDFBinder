# 画像保存ボタンのアイコンを E413 に変更 検証報告（Walkthrough）

## 1. 概要
Issue [#202](https://github.com/shota4327/PDFBinder/issues/202) に基づき、リボンツールバーの「編集」タブに配置されている「画像保存」ボタンおよび画像書き出しダイアログ（オーバーレイ）のアイコングリフを `&#xEB9F;` から `&#xE413;` に変更しました。また、基本設計書（`docs/basic_design.md`）のアイコン記述を同期更新しました。

## 2. 変更内容
1. `src/PDFBinder.App/MainWindow.xaml`:
   - リボンツールバー「編集」タブ「ページ構成・抽出」グループの「画像保存」ボタンのアイコン Text を `&#xE413;` に変更。
   - インアプリ・オーバーレイの画像書き出しダイアログのヘッダーアイコン Text を `&#xE413;` に変更。
2. `docs/basic_design.md`:
   - 「9.1 UI導線および起動」の画像保存ボタンのアイコン仕様記述を `&#xE413;` (Save / Image Export) に更新。
3. `Directory.Build.props`:
   - バージョンを `0.11.0` から `0.11.1` にインクリメント。
4. `CHANGELOG.md`:
   - バージョン `0.11.1` の変更履歴セクション（エンドユーザー向け表記）を追記。
