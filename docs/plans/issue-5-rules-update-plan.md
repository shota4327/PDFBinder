# PRマージ時単一EXE自動発行 & ドキュメント更新時Issue必須ルール整備 実装計画

Issue #5: 開発プロセスの確実性とトレーサビリティを担保するため、PRマージ時の単一EXE自動発行要件およびドキュメント更新のみの場合におけるIssue起票要件を開発規約（`GEMINI.md`）に明記・反映します。

## 確定仕様
1. **マージ完了時の単一EXE自動発行（必須）**:
   - PR マージおよび `master` ブランチの最新化・ローカルブランチ整理が完了した後は、必ず `powershell -ExecutionPolicy Bypass -File .\build.ps1` を実行し、`dist/PDFBinder.exe` に最新の単一実行可能ファイルを書き出し・更新すること。
   - 生成された EXE ファイルの出力パスおよびサイズをユーザーへの作業完了報告に明記すること。
2. **ドキュメント更新時における Issue 駆動開発の徹底**:
   - コード変更を伴わないドキュメント（`GEMINI.md`、`README.md`、`docs/*` 等）の更新のみであっても、例外なく必ず GitHub Issue をもとにブランチを作成して進めること（`master` ブランチへの直接コミットは厳禁）。
