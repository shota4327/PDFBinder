# Issue #45 印刷ダイアログ UI/UXデザイン調整（第3弾）実装計画

## 概要
ユーザーからの追加フィードバックに基づき、印刷ダイアログ（インアプリ・オーバーレイ）のレイアウト、コントロールの挙動および視認性をさらに洗練させます。

---

## 決定事項（ユーザー確認済み）
1. **プリンター・集約数ドロップダウン**:
   - タイトルバーのファイル選択と同様に「文字のすぐ右横に下三角アイコンが表示されるデザイン」とする。
   - 見た目はタイトルバー完全準拠のフラットスタイル（通常時は透明背景、ホバー時に枠線と背景色が浮き出るボーダレス形式、文字は明瞭な白文字）。
2. **ボタントグルの左詰め**:
   - 横幅いっぱいに引き伸ばさず、必要な幅を確保して左詰めで配置。
3. **条件付き表示（アコーディオン的配置）**:
   - 「ページ指定」テキストボックスは、ページ指定選択時のみ表示。
   - 「1Pに集約」の集約数選択は、集約選択時のみ表示。
4. **印刷範囲と印刷モードの縦並び**:
   - 選択肢を横並びから縦並びに変更し、直下に対応する入力欄・設定を展開。
5. **ダイアログの高さとスクロール**:
   - 高さ固定 750px を廃止し、最大高さ 750px（`MaxHeight="750"`）とする。
   - 外枠とヘッダー・フッターは固定表示とし、ウィンドウの高さが縮んだ場合は中央コンテンツ行が自動縮小し、左パネルの `ScrollViewer` でスクロール可能とする。
6. **部数フォントサイズ**:
   - 数字のフォントサイズを拡大（13pt → 15pt）し、視認性を向上。

---

## 変更ファイル・内容

### 1. `src/PDFBinder.App/App.xaml`
- `ModernDarkComboBoxStyle` の改修:
  - タイトルバーの `FileDropdownToggleButtonStyle` と同様のフラットスタイルへ変更（通常時 `Transparent`、ホバー時 `ControlHoverBrush`）。
  - `ToggleButton` 内部のレイアウトを `HorizontalAlignment="Left"` の `StackPanel`（または `DockPanel`）とし、選択テキストのすぐ右横に下三角アイコン（`&#xE5CF;`）を隣接配置。
  - テキストが確実に白文字（`TextPrimaryBrush`）で描画されるよう、`TextElement.Foreground` および `ContentPresenter` の設定を最適化。
  - ドロップダウン展開時のポップアップ枠線・背景・アイテムホバースタイルを統一。

### 2. `src/PDFBinder.App/MainWindow.xaml`
- 印刷オーバーレイの寸法調整:
  - `Height="750"` を削除し、`MaxHeight="750"`、`Margin="24,16"` に変更。
- 部数コントロール:
  - `TextBox` の `FontSize` を 13 から 15 に拡大。
- 用紙の向き・用紙サイズ・両面印刷:
  - `Grid` から `StackPanel Orientation="Horizontal"` へ変更し、各ボタントグルを左詰めで配置。各ボタンに適度な `Padding` と `Margin` を設定。
- 印刷範囲:
  - `StackPanel Orientation="Vertical"` で縦並びに配置。
  - 「ページ指定」テキストボックスとそのエラーメッセージを、`Settings.RangeType == Custom`（`CustomRangeToggle.IsChecked == true`）の時のみ表示（`BooleanToVisibilityConverter`）。
- 印刷モード:
  - `StackPanel Orientation="Vertical"` で縦並びに配置。
  - 集約数プルダウン（DockPanel）を、「1Pに集約」選択時（`NUpToggle.IsChecked == true`）の時のみ表示。

## 検証計画

- `dotnet test`: 既存の全単体テスト（304件）が 100% PASS することを確認。
- `dotnet build`: 警告・エラーがないことを確認。

### 手動検証・UI確認
- 印刷ダイアログを開き、以下を確認:
  1. プリンター選択・集約数選択が白文字で表示され、文字の直後に下三角が表示されていること。通常時はフラットで、ホバー時に背景色が変化すること。
  2. ボタントグルが左詰めになっていること。
  3. 印刷範囲・印刷モードが縦並びになっており、それぞれ「ページ指定」「1Pに集約」選択時のみ追加設定が表示されること。
  4. ウィンドウサイズを小さくした場合に、ダイアログが画面からはみ出さず、左パネルがスクロールすること。
  5. 部数の数字が大きく見やすくなっていること。
