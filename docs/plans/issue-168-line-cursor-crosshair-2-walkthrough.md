# Issue #168 直線ツールカーソルの十字線（クロスヘア）化 検証報告（Walkthrough）

## 1. 概要
直線ツール選択時のカーソル表示について、従来の定規アイコンバッジを廃止し、ペンの色・太さ・透明度を反映した円形プレビューの上下左右に、円と重ならないよう余白を空けた4本の直線（「＋」の字を形成する十字クロスヘア）を描画する方式へと刷新しました。

---

## 2. 変更内容の詳細

### 2.1 カーソル生成ロジックの刷新 (`PenCursorHelper.cs`)
- **定規アイコンの完全廃止**:
  - 定規バッジ描画処理（`DrawRulerBadge`, `SampleRulerColor`, `IsOnTickMark` 等）を削除。
- **十字クロスヘア（4方向直線）の描画 (`DrawCrosshairLines`)**:
  - **線の色**: シンプルな黒色単色（`#000000`、不透明度100%）。
  - **線の太さ**: `lineThickness = 1.0`（将来的な太さ調整に対応できるよう定数定義）。
  - **線の長さ**: `lineLength = 7.0`（「＋」の字として一目で認識できる十分な長さ）。
  - **余白**: `gap = 3.5`（円形プレビューの外周から約3.5px離れた位置から線を開始し、円と重ならない配置）。
  - **サブピクセル描画 (`DrawLineRect`, `ApplyBlackLinePixel`)**:
    - ピクセル境界との重なり度合い（カバレッジ）を計算し、端のピクセルに滑らかなアンチエイリアス処理を適用。
  - **キャンバスサイズとホットスポット**:
    - ホットスポットは円および十字線の幾何学的中心 `(hotspot, hotspot)`。
    - キャンバスサイズは円の半径と余白・線長さに応じて動的に計算（最小 32x32）。

### 2.2 単体テストの更新 (`PenCursorHelperTests.cs`)
- `DrawCrosshairLines_RendersExpectedPixels`:
  - 円形プレビューの上下左右に黒色（アルファ > 0、RGB = 0）のピクセルが正しく描画されていることを検証。
  - 円と十字線の間の余白領域（gap）には黒線ピクセルが描画されていないことを検証。

### 2.3 ドキュメントの同期更新
