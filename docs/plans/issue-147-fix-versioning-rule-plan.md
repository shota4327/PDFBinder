## 提案される変更内容

### 1. プロジェクト開発規約の改定
#### [MODIFY] `GEMINI.md`
- 「3.1 Git & ブランチ・プルリクエスト（PR）運用ルール」を改定:
  - **バージョンインクリメントとCHANGELOG更新の実施場所を作業ブランチ（機能PR内）に変更**:
    - 作業ブランチにおいて、変更内容に応じて `Directory.Build.props` のバージョンを自律的にインクリメント（新機能: マイナー `0.X.0`、不具合修正・改善・ドキュメント: パッチ `0.X.Y`）。
    - 作業ブランチにおいて、`CHANGELOG.md` の新バージョンセクションを確定・記述。
    - これにより、PRの変更差分（diff）でバージョン更新と変更履歴のレビューが可能となる。
  - **`master` ブランチでのコミットを完全禁止**:
    - PR通常マージ（`--merge`）および `master` の最新化・ブランチ整理後、`master` ブランチ上ではコミットを一切行わない。
    - 最新化されたマージコミットに対して、直ちにGitタグ（`git tag vX.Y.Z`、`git push origin vX.Y.Z`）を作成・プッシュする。
    - 続いて配布バイナリ発行スクリプト（`build.ps1`）を実行する。
- 「5. ドキュメントおよびルールの自律的・継続的アップデート」を改定し、上記ルールとの整合性を確保。

### 2. 基本設計書の改定
