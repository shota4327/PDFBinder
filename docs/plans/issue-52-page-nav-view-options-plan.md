# Issue #52 実装計画: ページ移動ボタン・表示オプションの追加

## 概要
ステータスバーの高さを約1.5倍に拡大し、左端にページ表示・移動ボタン（`< ページ [1] / 2 >`）、右端にズームコントロール（`[-] 100% [+]`）を追加します。
また、リボンの表示タブ内に「100%」「ウィンドウにあわせる（デフォルト）」「幅にあわせる」の表示オプションボタングループを追加し、詳細ビューにおけるウィンドウリサイズやカレントページ変更に連動した動的自動フィッティング表示を実現します。

---

## 決定事項（ヒアリング結果）
1. **表示オプションの追従挙動**:
   - モード追従型を採用。「ウィンドウにあわせる」「幅にあわせる」選択中は、ウィンドウのリサイズ時やカレントページ変更時にも自動で最適倍率を維持・再計算する。
   - ユーザーが手動でズーム（拡大・縮小ボタン、Ctrl+ホイール等）を操作した場合はカスタム固定倍率へ自動遷移する。
2. **表示オプションのUI配置形式**:
   - 3つの独立したラジオボタングループ形式（「100%」「ウィンドウ」「幅」）とし、リボン内の詳細・グリッド切り替えボタン群と同様のトーン＆マナーで現在の選択状態を明示する。詳細ビューのときのみ有効化する。
3. **ページ移動ボタンの適用範囲**:
   - 詳細ビュー限定とし、グリッドビュー表示中は「<」「>」および入力欄を非活性（IsEnabled=False）とする。
4. **ページ番号の直接入力**:
   - 「< ページ [ 1 ] / 2 >」の中央番号部分は編集可能なTextBoxとし、直接ページ番号を入力してEnterキーを押す（またはフォーカスアウト）で対象ページへ即時スクロールジャンプできるようにする。
5. **ステータスバーのレイアウト整理**:
   - 左端に総ページ数（`/ X`）が含まれるため、右端にあった「全 X ページ」は削除し、右端は `ProgressBar` と `[-] 100% [+]` のズームコントロールとする。
   - ステータスバー全体の高さを約1.5倍（MinHeight 36px）に拡大し、操作性を向上させる。
6. **表示オプションの倍率計算基準**:
   - ページごとにサイズが異なるドキュメントを考慮し、現在表示中のページ（カレントページ）の寸法を基準として計算する。

## 実装計画

### 1. View / ViewModel の設計・変更

#### A. 表示オプション（DetailViewFitMode）の導入
- **列挙型 `DetailViewFitMode` の定義**:
  - `None`（カスタム倍率・手動ズーム時）
  - `FitToWindow`（ウィンドウに合わせる・デフォルト）
  - `FitToWidth`（幅に合わせる）
  - `ActualSize`（100% 等倍）
- **`DetailEditorViewModel` への拡張**:
  - `FitMode` プロパティの追加（デフォルト: `DetailViewFitMode.FitToWindow`）
  - ビューポート寸法（`ViewportWidth`, `ViewportHeight`）の受け取り・保持
  - 倍率再計算メソッド `ApplyFitMode()`:
    - カレントページの寸法（`DisplayWidth`, `DisplayHeight`）とスクロールビューアの余白（Padding等）を考慮して `Zoom` を算出
    - `FitToWindow`: 縦横両方が収まるよう `Math.Min(wScale, hScale)`
    - `FitToWidth`: 横幅がぴったり収まるよう `wScale`
    - `ActualSize`: `Zoom = 1.0`
  - ウィンドウリサイズ時、およびカレントページ変更（スクロール時・移動時）に `FitMode != None` であれば自動再計算を実行
  - 手動ズーム（`ZoomIn`, `ZoomOut`, マウスホイール操作）時は `FitMode = DetailViewFitMode.None` にリセット
  - コマンド `SetFitModeCommand(DetailViewFitMode)`

#### B. ページ移動・ジャンプ機能の拡張
- **`DetailEditorViewModel` / `MainViewModel`**:
  - `CanGoToPreviousPage`, `CanGoToNextPage`: カレントページのインデックスに基づく活性・非活性制御
  - `GoToPreviousPageCommand`, `GoToNextPageCommand`: 前後ページへの移動
  - `CurrentPageNumber`: 1-based の現在ページ番号（双方向バインディング、入力値検証付き）
  - `GoToPage(int pageNumber)`: 入力されたページ番号へのスクロールジャンプ

#### C. ステータスバー UI の刷新（`MainWindow.xaml`）
- **高さ拡大**:
  - `MinHeight="36"`、`Padding="12,4"` を設定
- **左端**:
  - ページナビゲーションコンテナ（`<Button (前へ)> ページ <TextBox (ページ番号)> / <TextBlock (総ページ数)> <Button (次へ)>`）
  - 詳細ビュー時のみ活性、ドキュメント未読み込み時は非活性
- **中央**:
  - `StatusMessage`（ステータス情報テキスト）
- **右端**:
  - `ProgressBar`（非同期処理中）
  - ズームコントロール（`<Button (縮小)> <Button (拡大率リセット)> <Button (拡大)>`）
  - ボタンデザインは押しやすく洗練されたフラットボタンスタイル

#### D. 表示タブ（リボン）UI の拡張（`MainWindow.xaml`）
- 「表示モード（詳細/グリッド）」と「ズーム」の間に「表示オプション」グループを追加
- ラジオボタン形式:
  - `100%`: 等倍
  - `ウィンドウ`: ウィンドウに合わせる
  - `幅`: 幅に合わせる
- `IsEnabled="{Binding IsDetailViewActive}"` で詳細ビュー時のみ有効化

#### E. `DetailEditorView.xaml.cs` の連携
- `DetailScrollViewer` の `SizeChanged` イベントを購読し、ビューポートサイズを ViewModel へ伝達して動的追従を実現
