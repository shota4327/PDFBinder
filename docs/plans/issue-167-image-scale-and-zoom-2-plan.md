# 実装計画書: Issue #167（追加改修-2）画像編集時のズーム下限拡張および高DPI手書き太さ適正化

## 1. 概要
- **Issue**: #167 画像データの直接編集に対応する（追加改修-2）
- **背景と課題**:
  1. **ズーム下限（50%）による画面フィット不可**:
     - 高解像度（4000x3000px等）の画像を開いた際、ウィンドウサイズや幅に合わせるために20%〜25%程度の縮小が必要にもかかわらず、現在のズーム下限が50%（0.5）で固定されているため、画面からはみ出してしまう。
  2. **高DPI・大解像度画像での手書きツール極小化**:
     - キャンバスが巨大なpt寸法（例: 3000pt）になるため、A4用紙（595pt）基準で設計された手書きペンの太さ（1.0pt等）が相対的に極細（数ピクセル以下）となり、全体表示時にほとんど見えなくなってしまう。
     - また、スキャン画像（300 DPI等）のDPIメタデータが一律96 DPI換算されているため、A4スキャン書類が巨大化してしまっている。
- **目的**:
  - 案C（ハイブリッド方式）を採用し、PDFドキュメントへの悪影響（デグレ）を完全にゼロに保ちながら、画像の画面フィットおよび手書き体験を劇的に改善する。

---

## 2. 変更・実装方針

### 2.1 ズーム範囲の拡張（MinZoom 0.05化 ＆ スナップステップ追加）
1. **`ZoomHelper.cs`**:
   - `MinZoom` を `0.5` から `0.05`（5%）へ拡張。
   - `ZoomSnapSteps` に `[0.05, 0.1, 0.15, 0.2, 0.3, 0.4]` を追加。
   - `GetNextZoomIn` / `GetNextZoomOut` が 5% 〜 3200% の全28段階でスムーズに遷移するように更新。
2. **`PinchZoomHelper.cs`**:
   - `DefaultMinZoom` を `ZoomHelper.MinZoom`（0.05）に追従。
3. **サムネイル最小サイズの保護（`MainViewModel.cs`）**:
   - `MinThumbnailSize`: グリッドビューのサムネイルが極小（米粒サイズ）になるのを防ぐため、サムネイルの最小サイズは従来の 50%（110px）基準（`DefaultThumbnailSize * 0.5`）を維持・固定。

### 2.2 スキャン画像のDPIメタデータ認識（`ImageService.cs`）
1. **DPIメタデータ取得と物理寸法算出**:
   - `BitmapFrame` から `DpiX`, `DpiY` を取得。
   - スキャン画像等で明示的なDPI（`DpiX >= 120.0`）が埋め込まれている場合:
     - `widthPt = frame.PixelWidth * 72.0 / frame.DpiX`
     - `heightPt = frame.PixelHeight * 72.0 / frame.DpiY`
     - これにより、300 DPIのA4スキャン画像（2480x3508px）は自動的に `595 x 842 pt`（A4サイズ）として読み込まれ、PDFと完全に同じ寸法・比率になる。
   - DPIメタデータ未設定または標準解像度（96 DPI以下）の写真等の場合:
     - 従来のピクセル等倍原則（`PixelWidth * 72.0 / 96.0`）を維持。

### 2.3 高解像度画像における手書きストローク太さ・カーソルの自動適正化
1. **ストロークスケーリング係数の導入（`DetailEditorViewModel.cs`）**:
   - 画像ドキュメント（`DocumentKind == DocumentKind.Image`）の場合、基準A4短辺（595.0 pt）に対する画像の最小辺の比率（`scale = Math.Max(1.0, Math.Min(page.Width, page.Height) / 595.0)`）を算出。
   - ペン・蛍光ペン・消しゴムの太さ、およびホバープレビューカーソルの太さにこのスケーリング係数を適用。
   - これにより、4000x3000pxの巨大写真であっても、画面全体を見ながら書いた際に「通常のA4用紙と同じ視覚的太さ・書き心地」が常に保証される。
2. **PDFドキュメントの完全保護**:
   - PDFドキュメントの場合はスケーリング係数を `1.0`（無補正）とし、既存の太さプリセット・描画・カーソル表示を 100% そのまま維持。
