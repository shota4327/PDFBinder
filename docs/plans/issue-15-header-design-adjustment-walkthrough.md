# ヘッダーデザイン調整の検証報告 (Walkthrough)

## 概要
Issue #15 に基づき、メイン画面上部のヘッダー（ツールバー）のレイアウトを調整しました。左端のアプリアイコンを削除して左詰めにし、各ボタングループの配置順を整理しました。

## 実施した変更点

### 1. ツールバー左端のアプリアイコン削除
- [MainWindow.xaml](file:///c:/Git/PDFBinder/src/PDFBinder.App/MainWindow.xaml)
  - `Border` 内左端に配置されていた `Image` 要素（`Assets/icon.png`）を削除し、ボタン全体を左詰めに配置しました。
  - ウィンドウヘッダー（タイトルバー）アイコンは維持されています。

### 2. ファイル操作グループの再編成
- 「PDF追加結合」ボタンを「開く」ボタンの右横に移動し、ラベルテキストを「追加」に変更しました。
- 並び順: 【開く】 ➔ 【追加】 ➔ 【保存】 ➔ 【別名保存】

### 3. ページ構成・抽出グループの新設
- 「白紙追加」ボタンの右横に「選択抽出」および「全分割」ボタンを移動し、1つの機能グループとしてまとめました。
- 並び順: 【白紙追加】 ➔ 【選択抽出】 ➔ 【全分割】

### 4. 全体ボタングループの配置構成
ツールバー全体のグループ並び順は以下の通りです：
1. **ファイル操作**: 【開く】【追加】【保存】【別名保存】
2. **ページ構成・抽出**: 【白紙追加】【選択抽出】【全分割】
3. **ページ編集**: 【左回転】【右回転】【削除】
4. **履歴**: 【元に戻す】【やり直す】
5. **表示ズーム**: 【縮小】【拡大】（グリッド俯瞰時のみ表示）

### 5. ドキュメントの同期更新
- [docs/basic_design.md](file:///c:/Git/PDFBinder/docs/basic_design.md): ツールバー構成の説明を最新のグループ編成に更新
