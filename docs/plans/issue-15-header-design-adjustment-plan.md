# ヘッダーデザイン調整の実装計画 (Issue #15)

ヘッダー（ツールバー）のレイアウトを調整し、アプリアイコンを削除して左詰め配置にするとともに、ボタンの配置・グルーピングを整理して直感的な操作性を向上させます。

## ユーザー確認済み事項（grill-me 合意事項）
1. **アプリアイコン**: ツールバー左端の `icon.png` は削除し、全体を左詰めに配置。
2. **「追加」ボタン**: 「PDF追加結合」ボタンを「開く」ボタンの右横に移動し、ラベルを「追加」に変更（アイコン・ツールチップは維持）。
3. **ファイル操作グループ**: 【開く】【追加】【保存】【別名保存】の順で1つのグループに集約。
4. **ページ構成・抽出グループ**: 【白紙追加】【選択抽出】【全分割】を1つのグループに集約。
5. **全体グループ並び順**:
   - グループ1: ファイル操作（開く、追加、保存、別名保存）
   - グループ2: ページ構成・抽出（白紙追加、選択抽出、全分割）
   - グループ3: ページ編集（左回転、右回転、削除）
   - グループ4: 履歴（元に戻す、やり直す）
   - グループ5: ズーム（縮小、拡大 ※グリッド俯瞰時のみ表示）
