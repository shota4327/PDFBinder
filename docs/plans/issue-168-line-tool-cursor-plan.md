# 実装計画: 直線ツール選択時のカーソル変更 (Issue #168)

## 1. 概要
詳細エディタにおいて直線ツール（または直線描画トグルON時）が選択された際、従来の十字（`Cursors.Cross`）カーソルではなく、通常のペン・蛍光ペンと同様の「描画色・太さ・透明度を反映した円形プレビュー」を表示し、その右上に視認性の高い「定規アイコン（ルーラーバッジ）」を常時表示するようにカーソル表示を刷新します。

---

## 2. 決定した設計仕様（/grill-me による合意事項）

1. **対象ツールおよび属性反映**:
   - 通常ペン・蛍光ペンの両方で、直線トグルON時（および `EditorToolMode.StraightLine` 時）に適用。
   - 現在選択されているペンの「描画色」「太さ」「ズーム倍率」「透明度（蛍光ペン時は半透明）」をそのまま円形プレビューに反映。
2. **ホットスポット（描画開始基準点）**:
   - 常に「円形プレビューの中心」をカーソルのホットスポットとし、マウスをクリックした位置から正確に直線が描画開始されるようにする。
3. **定規アイコンのデザインと視認性**:
   - 斜め45度の目盛り付き定規デザインを採用。
   - 白地・黒地のどちらのPDFドキュメント上でも埋もれず視認できるよう、黒色ベース＋白色の縁取り（または明暗ハイコントラスト）を付与。
   - 定規アイコンのサイズは約14〜16px程度の固定サイズとし、ズームや太さに影響されず常に明瞭に認識可能とする。
4. **定規アイコンの配置（オフセット）**:
   - 円形プレビューの外周（半径）＋一定のマージン（約2〜3px）をあけた右上位置に配置。
   - ペン太さの変更やズームイン・アウトによって円が拡大・縮小しても、定規アイコンが円に埋もれることなく、常に円の外周のすぐ右上に追従する。
5. **動的更新とキャッシュ**:
   - ペン色、太さ、ズーム倍率、ツールモード、直線トグルの変更に連動して即座にカーソルを更新。
   - `PenCursorHelper` に直線用カーソルのキャッシュ機構を導入し、同一属性でのパフォーマンス低下を防止。

---

## 3. 影響範囲と実装ステップ

### Step 1: `PenCursorHelper` の拡張
- `PenCursorHelper` に直線ツール（定規アイコン付き円形プレビューカーソル）生成ロジックを追加。
  - `IsCircleCursorTool(EditorToolMode toolMode, bool isStraightLine)` または直線ツールのサポート判定を追加。
  - `GetCursor` メソッドに直線モード用の引数 `bool isStraightLine` を追加（または直線専用の取得メソッドを用意）。
  - 定規アイコンを生成・合成するピクセル描画ルーチン `DrawRulerBadge`（45度傾斜の定規アイコン＋白縁取り＋目盛り）を実装。
  - カーソル画像全体の寸法（キャンバスサイズ）を中心のホットスポットおよび右上の定規アイコンが収まる十分なサイズに設定。
  - キャッシュキーに直線モードフラグを含め、効率的なキャッシュ管理を行う。

### Step 2: `EditorInkCanvas` のカーソル制御の更新
- `ApplyDrawingOrStraightLineMode()`:
  - 直線モード時（`IsStraightLineActive == true`）に `Cursors.Cross` ではなく、定規アイコン付きのペンプレビューカーソルを設定。
- `UpdateEditingMode()`:
  - `EditorToolMode.StraightLine` 時のカーソル設定を定規アイコン付きカーソルに変更。
- `UpdateCursor()`:
  - 直線モード時にも色・太さ・ズーム倍率の変更に応じてカーソルを動的に更新。

### Step 3: 単体テストの追加と既存テストの更新
- `PenCursorHelperTests.cs`:
  - 直線モード時のカーソル取得が非nullであり、通常ペンカーソルと異なる（定規アイコン付き）インスタンスを返すことの検証。
  - キャッシュ動作、ズーム変更時の挙動検証。
  - 定規アイコンのピクセル描画（ハイコントラスト輪郭・目盛り）の検証。
- `DetailEditorStraightLineTests.cs`:
  - 従来 `Assert.Equal(Cursors.Cross, canvas.Cursor)` となっていたテスト箇所を、新仕様（十字ではなく定規付きプレビューカーソルが設定されること）に更新。

---

## 4. 検証計画
- `dotnet test`: すべての単体テストが PASS すること（既存テストの破壊がないこと）。
- `dotnet build`: 警告・エラーなくビルドが成功すること。
- 手動動作確認（またはSTAテストによる描画属性検証）:
  - 直線トグルON時、ペンの色・太さに応じた円と右上に定規アイコンが表示されること。
  - 蛍光ペン選択時に半透明円＋定規アイコンが表示されること。
  - ペン太さ・色・ズーム倍率変更時に定規アイコンが追従し、破綻しないこと。
