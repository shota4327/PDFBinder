# Issue #45 印刷機能 実装計画書

## 1. 概要
本計画は、PDF Binder における「印刷機能（Issue #45）」の実装計画書です。
ユーザーインタビュー（`/grill-me`）により決定したUI/UXデザイン方針、設定項目、面付けロジック、プレビュー表示、印刷実行エンジン、および既存アーキテクチャとの統一性を完全に反映した設計・実装手順を定義します。

---

## 2. 決定した要件と仕様詳細

### 2.1 画面レイアウト・表示形式（インアプリ・オーバーレイ）
- **表示形態**: 既存の「未保存変更確認ダイアログ」と同じデザイン言語（半透明暗幕 `#80000000` + ダークテーマ角丸カード）によるインアプリ・オーバーレイ。
- **カードサイズ**: 幅 880px × 高さ 600px（ウィンドウサイズに応じ MaxWidth / MaxHeight 制限）。
- **左右2分割構成**:
  - **左側（設定パネル / 幅約 320px）**:
    - 上部: プリンター選択（ComboBox、OS既定プリンターを初期選択）
    - 部数設定: 1〜99部（数値入力・ステッパー付き、デフォルト: 1）
    - 印刷の向き: 縦 / 横（デフォルト: 縦）
    - 用紙サイズ: A4 / A3（デフォルト: A4）
    - 両面印刷: 片面 / 両面（長辺とじ） / 両面（短辺とじ）（デフォルト: 片面）
    - 印刷範囲:
      - すべてのページ（デフォルト）
      - 現在のページのみ
      - カスタム指定（「1-3, 5, 7-10」等）
        - リアルタイム入力検証（赤枠・エラーメッセージ表示、無効時は印刷ボタン無効化）
    - 印刷モード:
      - サイズに合わせる（デフォルト）
      - １ページに集約（N-up: 2ページ / 4ページ / 8ページ選択）
      - 冊子形式（製本: 二つ折り中綴じ面付け、自動で横向き・両面（短辺とじ）に連動、4の倍数で白紙補完）
  - **右側（プレビュー領域 / 残り幅）**:
    - 用紙アスペクト比・余白・印刷モード（単一、集約、冊子面付け）を忠実に反映した用紙プレビューカード（自動 Fit 表示）。
    - プレビュー下部ナビゲーションバー（「◀ 前の用紙」「1 / N」「次の用紙 ▶」）。
  - **フッター（下部アクションバー）**:
    - 進行状況表示（印刷中: プログレスバー & 「印刷中... X / Y ページ」）
    - アクションボタン: 「印刷」（Primary）、「キャンセル」（Secondary）
- **キーボードショートカット**:
  - `Ctrl+P`: 印刷ダイアログの起動
  - `Escape`: 印刷ダイアログのキャンセル・閉じる
  - `Enter`: 印刷実行（カスタム指定エラー時等は無効）

### 2.2 設定のライフサイクル
- アプリ起動時は常に初期デフォルト値に設定。
- アプリ起動中は設定変更を保持（別のPDFに切り替えても前回の設定が残る）。

### 2.3 印刷エンジンと面付けロジック
- **印刷方式**: WPF `System.Printing`（`PrintDialog` / `PrintQueue` / `DrawingVisual`）を活用。
- **レンダリング**: 既存の `PdfiumRenderer` を活用し、高解像度（300 DPI）で各ページをラスタライズして配置。
- **面付けロジック (`PrintLayoutCalculator`)**:
  - **通常（サイズに合わせる）**: 1用紙に1ページをアスペクト比維持で最大化配置。
  - **N-up集約（2 / 4 / 8ページ）**:
    - 2-up: 用紙を2等分（横向きの場合は縦2分割、縦向きの場合は横2分割）。
    - 4-up: 用紙を2×2の4等分。
    - 8-up: 用紙を2×4の8等分。
  - **冊子形式（Booklet）**:
    - 対象ページ数を4の倍数に切り上げ（不足分は白紙）。
    - Nページの場合、用紙 k 枚目の表面（外側）: [Page N - 2k + 1, Page 2k]、裏面（内側）: [Page 2k + 1, Page N - 2k] の順に配置。
    - 横向き・両面（短辺とじ）で二つ折りにした際に正しい書籍の順序となる。

## 4. 検証計画
1. **単体テスト**:
   - `dotnet test` により、新規追加する面付けロジック、範囲パース、ViewModelの全テストが PASS することを確認。
2. **ビルド検証**:
   - `dotnet build` で警告・エラーがないことを確認。
3. **手動UI/動作検証**:
   - PDFファイルを開き、「印刷」ボタンまたは `Ctrl+P` でダイアログが表示されること。
   - 既存の未保存確認ダイアログと調和したダークテーマで表示されること。
   - 各設定（プリンター、部数、向き、A4/A3、両面、範囲、Fit/集約/冊子）がスムーズに切り替わり、右側のプレビューがリアルタイムに更新されること。
   - 不正なカスタム範囲を入力した際に赤枠とエラー表示になり、印刷ボタンが無効化されること。
   - 冊子形式選択時に自動で横向き・両面（短辺とじ）になること。
   - Escキーでダイアログが閉じること。
   - アプリ起動中に設定を変更し、一度閉じて再度開いたときに設定が保持されていること。
