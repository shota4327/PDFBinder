# Issue #77 ステータスバーの半透明化およびサイズ拡大 実装計画書

## 概要
下部ステータスバーを半透明化し、背後のコンテンツ（PDFグリッドおよび手書きエディタ）の上に重ねて表示するオーバーレイ形式へ変更します。併せて、ステータスバー全体の高さおよび内部コントロール（ボタン、入力欄）のサイズを約5px拡大し、モダンで操作しやすいUIを実現します。

---

## ユーザー確認・合意事項
ヒアリング（`/grill-me`）により合意済みの仕様：
1. **オーバーレイ配置**: コンテンツ領域（Grid Row 2）の下端に重ねて配置し、背後のドキュメントがステータスバー越しに透けて見えるようにする。
2. **下端ドック型スタイル**: 画面最下部の横幅いっぱいにフィットさせ、上部境界線（`#E2E8F0`）と半透明白背景（`#E6FFFFFF`、約90%不透明度）を設定。
3. **最下部スクロール余白**: 最下部までスクロールした際に最後のページやサムネイルがステータスバーに隠れないよう、各ビューのスクロール領域下部にステータスバー相当（約45〜56px）のパディングを確保。
4. **サイズ拡大（約5px）**:
   - ステータスバー全体の高さ: `MinHeight="36"` → `MinHeight="42"`、`Padding="12,3"` → `Padding="12,5"`
   - 内部ボタン: `Width="26" Height="26"` → `Width="28" Height="28"`
   - ページ番号入力欄: `Height="24"` → `Height="26"`
   - ズームリセットボタン: `Height="26"` → `Height="28"`

---

## 変更対象ファイルと詳細設計

### 1. [MainWindow.xaml](file:///c:/Git/PDFBinder/src/PDFBinder.App/MainWindow.xaml)
- **レイアウト構造**:
  - `Grid.RowDefinitions` の最下行（Row 3: `Height="Auto"`）を廃止し、コンテンツ領域（Row 2: `Height="*"`）がウィンドウ下端まで広がるように変更。
  - ステータスバー `Border` を `Grid.Row="2"` に配置し、`VerticalAlignment="Bottom"` および `Panel.ZIndex="10"` を指定してコンテンツの手前にオーバーレイ表示。
- **スタイル・透過性**:
  - `Background="White"` → `Background="#E6FFFFFF"`（約90%不透明度）。
  - `MinHeight="36"` → `MinHeight="42"`。
  - `Padding="12,3"` → `Padding="12,5"`。
- **内部コントロールのサイズ拡大**:
  - ページ移動ボタン（前へ・次へ）: `Width="28" Height="28"`。
  - ページ番号 TextBox: `Height="26"`。
  - ズームボタン（縮小・拡大）: `Width="28" Height="28"`。
  - ズームリセットボタン: `Height="28"`。

### 2. [GridView.xaml](file:///c:/Git/PDFBinder/src/PDFBinder.App/Views/GridView.xaml)
- **スクロール領域パディング調整**:
  - `ScrollViewer` の `Padding="20"` を `Padding="20,20,20,56"` に更新。
  - 最下部までスクロールした際、最後の行のカードや操作ボタンが半透明ステータスバーの下に隠れることなく完全に表示・クリック可能にします。

### 3. [DetailEditorView.xaml](file:///c:/Git/PDFBinder/src/PDFBinder.App/Views/DetailEditorView.xaml)
- **スクロール領域パディング調整**:
  - `DetailScrollViewer` の `Padding="5"` を `Padding="5,5,5,48"` に更新。
  - 縦スクロール時にページ下端がステータスバーに隠れず完全に閲覧・編集可能にします。
