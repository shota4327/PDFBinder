# 画像保存ボタンのアイコンを E413 に変更 実装計画

## 1. 概要
リボンツールバーの「編集」タブに配置されている「画像保存」ボタンおよび画像書き出しダイアログのアイコンフォントグリフを、現在の `&#xEB9F;` から `&#xE413;` に変更します。また、基本設計書（`docs/basic_design.md`）の記載も合わせて更新します。

## 2. 変更対象ファイル
1. `src/PDFBinder.App/MainWindow.xaml`
   - リボン「編集」タブ「ページ構成・抽出」グループ内の「画像保存」ボタン（`ShowExportImagesDialogCommand`）のアイコン Text を `&#xE413;` に更新。
   - インアプリ・オーバーレイの「画像書き出し」ダイアログヘッダー内のアイコン Text を `&#xE413;` に更新。
2. `docs/basic_design.md`
   - 第9章「9.1 UI導線および起動」のリボンツールバー「画像保存」ボタンのアイコングリフ記述（`&#xEB9F;`）を `&#xE413;` に更新。

## 3. 検証計画
1. ビルド検証:
   - `dotnet build` を実行し、ビルドエラーや警告がないことを確認。
2. テスト検証:
   - `dotnet test` を実行し、既存のすべての単体テストが 100% PASS することを確認。

## 4. リリース準備（PR作成時）
1. `Directory.Build.props` のパッチバージョンをインクリメント。
2. `CHANGELOG.md` に一般利用者向けにアイコン更新の旨を記載し、`## [Unreleased]` セクションを整備。
