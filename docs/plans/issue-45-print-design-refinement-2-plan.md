# Issue #45 印刷機能 デザイン調整 実装計画書（2回目作業）

## 1. 概要
本計画は、Issue #45「印刷機能」について、ユーザーからのデザインフィードバック（`/grill-me`）に基づくUI/UX調整の第2次実装計画書です。

---

## 2. 決定した変更仕様詳細

1. **オーバーレイのサイズ・レイアウト調整**:
   - 幅: 表示領域の左右幅いっぱいに連動拡大（`HorizontalAlignment="Stretch"`, 左右マージン `24px`）。
   - 高さ: `750px`（ウィンドウサイズに応じ `MaxHeight="780"` 内で収束）。
   - 右側プレビュー領域が左右拡大分すべてを活用し、用紙全体が広々と高精細に自動Fit表示されるように調整。

2. **印刷アイコンの刷新**:
   - リボンツールバーの「印刷」ボタンおよび印刷ダイアログヘッダーのアイコンを `&#xE8AD;`（Material Symbols の print アイコン）に変更。

3. **部数コントロールの一体化デザイン**:
   - ウィンドウ右下のステータスバー拡大率コントロール（ズーム）と同様に、独立ボタンではなく単一の角丸ボーダー（`Border Background="#1E1E1E"`）内に `[-]` `[ 1 ]` `[+]` を一体化配置。
   - プラス・マイナスの文字・アイコンサイズを拡大（14px）。

4. **選択肢のボタントグル（Segmented Control）化**:
   - ラジオボタンを廃止し、ボタンスタイル（`DarkToggleRadioButtonStyle`）による直感的なトグルボタンに統一。
   - **用紙の向き**: `[ 縦 ] [ 横 ]`（横並びトグル）
   - **用紙サイズ**: `[ A4 ] [ A3 ]`（横並びトグル）
   - **両面印刷**: `[ 片面 ] [ 両面（長辺とじ） ] [ 両面（短辺とじ） ]`（横並びトグル）
   - **印刷範囲**: `[ すべてのページ ] [ 現在のページのみ ] [ ページ指定 ]`（横並びトグル）＋直下にカスタム入力欄
   - **印刷モード**: `[ サイズに合わせる ] [ １ページに集約 ] [ 冊子形式（製本） ]`（トグル）

5. **プルダウンのタイトルバー風デザイン統合＆選択文字表示バグ修正**:
   - プリンター選択および集約数選択のプルダウンにおいて、タイトルバーのファイル切り替えプルダウンと同様のスタイル（`SurfaceBorderBrush` 枠線、`#1E1E1E` 背景、下向き矢印 `&#xE5CF;`、角丸ドロップダウン）を適用。
   - 選択中のテキストが消えるバグを解消し、現在選択中のアイテム名が確実に明瞭表示されるカスタムコントロール/テンプレートを実装。
